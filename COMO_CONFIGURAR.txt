KORE FINANCE API - WEB MOBILE AULA 7

CONFIGURACAO SIMPLIFICADA PARA WINDOWS

1) SEGURANCA DO MONGODB ATLAS
- Como uma senha apareceu em um print durante a configuracao, troque a senha do usuario koreuser no MongoDB Atlas antes de usar o projeto.
- Para evitar problemas na URL, prefira uma senha forte formada por letras e numeros.
- Em Network Access, confirme que seu IP atual esta liberado.

2) FORMA MAIS FACIL DE INICIAR
- Extraia o projeto.
- Clique duas vezes em INICIAR_KORE.cmd.
- Na primeira execucao, o arquivo .env sera criado e aberto no Bloco de Notas.
- Troque somente SUA_SENHA pela NOVA senha do usuario koreuser.
- Salve e feche o Bloco de Notas.
- O script executara npm.cmd install, compilara o TypeScript diretamente e iniciara a API com Node.
- O projeto nao depende do Nest CLI nem do webpack para iniciar.

3) CONEXAO
O arquivo .env deve conter:
MONGODB_URI=mongodb+srv://koreuser:SUA_SENHA@korecluster.gazpojk.mongodb.net/kore_finance?retryWrites=true&w=majority

IMPORTANTE:
- O arquivo .env esta no .gitignore e NAO deve ser enviado ao GitHub.
- Nunca publique usuario e senha reais do MongoDB.

4) ENDPOINTS
API: http://localhost:3000
POST: http://localhost:3000/transacoes
GET:  http://localhost:3000/transacoes

Exemplo de POST:
{
  "descricao": "Conta de Luz",
  "valor": 180.50,
  "tipo": "despesa",
  "categoria": "Moradia",
  "consumoConsciente": true
}
